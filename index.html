FAQ

Preguntas Frecuentes

Resolvemos tus dudas más comunes sobre nuestros productos y servicios.

¿Puedo probar el software antes de comprarlo?

¡Sí! Ofrecemos una licencia de prueba gratuita por tiempo muy limitado. Esta licencia te da acceso total a todas las capacidades del software para que puedas evaluarlo sin compromiso. Solo se otorga una licencia de prueba por usuario para garantizar un uso justo del servicio. Si después de probarlo decides que no es para ti, no hay ninguna obligación de compra. Es nuestra forma de darte tranquilidad antes de tomar tu decisión.

¿Qué software se conecta por UART/COM?

Únicamente Console TVFix Pro v3 utiliza comunicación directa por puerto serie UART/COM para diagnóstico y modificación de parámetros. MstarTool 3 trabaja directamente con archivos de firmware (dumps) sin necesidad de conexión física al televisor.

¿Con qué marcas o chipsets funciona cada herramienta?

  • Console TVFix Pro v3: Amplia compatibilidad para trabajo MSTAR, REALTEK, MEDIATEK, SONY DTV / MT58XX, NUGGUET, PANASONIC, HISILICON, AMLOGIC, NOVATEK y SAMSUNG.
  • MstarTool 3: Exclusivo para dispositivos con chipset Mstar.

¿Cómo funciona el sistema de licencias?

Nuestro software utiliza un sistema de licencias con firma digital RSA-3072. La licencia se vincula a la huella única de tu dispositivo (hardware). No requiere conexión permanente a internet para funcionar. El proceso de activación es simple: generas una solicitud desde el software, nos la envías por WhatsApp, y te devolvemos la licencia firmada para que la importes.

¿Hay versiones anteriores a la venta?

No. Las versiones anteriores de Console TVFix Pro y MstarTool ya no están a la venta. Solo se comercializan Console TVFix Pro v3 y MstarTool 3. Los clientes registrados de versiones anteriores pueden solicitar su actualización gratuita contactándonos directamente.

¿Qué sistemas operativos necesito?

  • Console TVFix Pro v3: Windows 10/11 de 64 bits, o Android 9.
  • MstarTool 3: Compatible desde Windows 7 en adelante (32 y 64 bits).

¿Puedo usar el software en varios dispositivos?

Cada licencia está vinculada a un dispositivo específico. Si necesitas usar el software en múltiples dispositivos, contáctanos para conocer las opciones de licencias multi-dispositivo. También ofrecemos el servicio de desactivación para transferir tu licencia a un nuevo dispositivo.

¿Cómo actualizo si ya compré una versión anterior?

Los clientes registrados de Console TVFix Pro v1 y v2 pueden solicitar la actualización gratuita a v3 contactándonos directamente. Verificamos los datos de compra y gestionamos la migración personalmente.

¿Qué métodos de pago aceptan?

Aceptamos pagos por PayPal. Para coordinar el pago y la entrega, escríbenos directamente por WhatsApp y te guiaremos en el proceso.
